# bot_service — локальные правила

Дополняет корневой `AGENTS.md`. Сервис законсервирован.

## Консервация

- Новые сценарии, промпты, провайдеры LLM и модели БД не добавлять.
- На VDS сервис не разворачивать и в прод-compose не включать.
- Любая правка в каталоге оставляет зелёным `pytest` этого сервиса: он входит в `make check`.

## Что нельзя ломать

- Поведение, которое фиксируют тесты в `tests/`. Красный тест чинить точечно, без переписывания агента.
- Вызов калькуляторов по slug и параметрам запроса. Формулы стоимости живут в `calc_service`.
- Секреты Telegram и LLM: они остаются в корневом `.env`.

## Возврат к разработке

Пока человек явно не снял консервацию, работа ведётся только локально.

Сначала `make bot-up` (остановка — `make bot-down`), затем `python -m pytest tests -q` из этого каталога. На прод бот при этом не выкатывается.
