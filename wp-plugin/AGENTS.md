# wp-plugin — локальные правила

Дополняет корневой `AGENTS.md`. Каталог — плагин-мост `insain-calc-bridge` (`insain-calc-bridge.php`, `js/insain-calc-bridge.js`).

## Bridge — тонкий адаптер

- В JS и PHP нет формул цены. Плагин собирает поля формы и вызывает API `calc_service` (`POST /api/v1/calc/{slug}` и связанные options/schema).
- Расхождение суммы с сайтом правится в калькуляторе или в маппинге полей формы.
- Custom JS форм, уже переведённых на API, лежит в этом каталоге и выкатывается вместе с плагином.

## Деплой плагина

На прод плагин попадает архивом через `wp plugin install <zip> --force --activate` от пользователя `www-data`. Цепочка архивации и `scp` — в корневом `AGENTS.md`. Отдельные файлы в `wp-content` не подкладывать.

## Формы ezFC

Структуру формы правят в админке ezFC, затем снимают снимок в репозиторий. Снимок нужен для истории и diff. Обратный импорт в ezFC ломает id элементов, поэтому заливки из снимка нет.

- Как снимать и какими каналами пользоваться: `docs/site/access-tools.md`, раздел «Принятый режим».
- Как перевести форму на API: `docs/ezfc-api-migration.md`.
