# metrics-baseline

Статус: заблокировано: человек
Сложность: средняя
Implementer: не нужен
Reviewer: Auto
Site ops: Grok 4.7
Почему: на проде и во внешних API (Метрика, amoCRM) только чтение; секреты вне git; цели G3 и G4 пишутся после «да» человека.
Чат: Site ops после того, как человек передал доступы вне git.

## Цель

В `docs/vision.md` у G3 и G4 стоят текущие значения (заявки/заказы и визиты из поиска за последний полный месяц) и предложенные целевые числа. Секреты в git не попадают.

## Контекст и ссылки

- `docs/vision.md` G3, G4
- Заказы WooCommerce — wp-cli на VDS, ключ не нужен
- Яндекс Метрика — OAuth на чтение и номер счётчика
- amoCRM — API-ключ
- Остальное не открывать

## Scope

На проде / вне git (Site ops):

1. Человек передаёт вне репозитория: номер счётчика Метрики, OAuth-токен Метрики (чтение), API-ключ amoCRM. Куда класть на машине агента — `.env` в корне (уже в gitignore) или менеджер секретов; значения в «Результат» не писать.
2. Снять заказы WooCommerce за прошлый полный месяц (`wp post list --post_type=shop_order` / отчёт Woo — как получится без PII).
3. Снять визиты из поиска и цели/заявки Метрики за тот же месяц.
4. Снять число новых сделок amoCRM за тот же месяц (воронка — с человеком, если их несколько).
5. Предложить целевые значения G3/G4 в чате; в `docs/vision.md` пишет человек или Analyst после «да».

## Файлы

- `docs/vision.md` — только колонки «Сейчас» и «Цель» у G3/G4, после подтверждения
- `.env` — секреты, не коммитить

## Не-scope

- Дашборд `--live` в CI
- Запись токенов в git, `STATUS.md`, журнал

## Критерии приёмки

- [ ] В чате (не в git) есть три числа за прошлый месяц: заказы Woo, визиты из поиска, сделки amoCRM
- [ ] `git grep -i "y0_\|oauth\|amocrm" -- ':!.env'` — совпадений с переданными секретами нет
- [ ] После «да» человека в `docs/vision.md` у G3 и G4 заполнены «Сейчас» и «Цель»

## Проверки

- [ ] Self-review — секретов нет в diff
