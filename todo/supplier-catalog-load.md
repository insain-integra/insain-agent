## Scope

1. Бэкап БД перед загрузкой.
2. Загрузка по одному поставщику: Проект 111, затем Happygifts, затем Oasis. После каждого — сверка числа товаров с фидом и выборочная проверка 5 карточек (цена, остаток, картинка, рубрика).
3. С человеком — какие рубрики и пункты меню открыть под новые товары (сейчас 16 разделов «Сувенирной продукции» пусты).
4. Проверка расписания: следующее событие обновления в планировщике и один прошедший запуск в логе.
5. С человеком — судьба insainParse и его таблиц (выключение удаляет таблицы).
