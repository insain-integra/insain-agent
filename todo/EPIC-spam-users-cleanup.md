# EPIC-spam-users-cleanup

Статус: черновик
Цель: отложено (`docs/vision.md`)

## Цель

Массовые спам-аккаунты (~тысяча, по оценке владельца ~99% спам) удалены с https://insain.ru без потери админов, shop_manager и реальных клиентов с заказами/перепиской. До удаления — бэкап БД и согласованный с человеком критерий «спам» + белый список. Эпик стартует после того, как регистрация уже ужесточена (`EPIC-antispam-recaptcha`), иначе аккаунты набьют снова.
