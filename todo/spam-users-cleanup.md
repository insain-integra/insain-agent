## Цель

Спам-аккаунты на https://insain.ru удалены по согласованному критерию. Админы, shop_manager и реальные клиенты (заказы, белый список) на месте. До любого удаления есть бэкап БД и записанный план отката.

## Scope

1. Только чтение: сводка пользователей по ролям, числу без заказов, дате регистрации (агрегаты в «Результат», без выгрузки всех email в git).
2. С человеком согласовать критерий «спам» и белый список (id/логины админов и известных клиентов).
3. Бэкап: `sudo -u www-data wp db export /tmp/insain-db-before-spam-cleanup.sql --path=/var/www/insain.ru` (путь уточнить на VDS; не коммитить дамп).
4. После явного «можно удалять» — пакетное удаление через wp-cli по критерию; не трогать роли `administrator`, `shop_manager` и whitelist.
5. Отчёт: сколько удалено / оставлено / сомнительных отложено.

Распределение: прод без git — всё делает Site ops. Каждый шаг удаления — с подтверждения человека. Reviewer смотрит отчёт Site ops с выводами команд.
