# EPIC-pipeline-skills

Статус: черновик

## Цель

В `.cursor/skills/` лежат четыре рецепта. Форма 69 CalcPlaque на странице наградных плакеток переведена на `insaincalc.calcApi('plaque', …)` так: сверка расчётов, дубль на черновик или приватный товар, отладка на боевом API, затем то же на боевой форме.

Рецепты нового калькулятора и смены цены в JSON в этом эпике только написаны. Чекбокс 5.5 в `docs/refactoring-plan.md` из-за этого не закрывается.

## Задачи

- `todo/skills-recipes.md` — четыре skill. Роль говорит, кто смотрит; skill — как делать руками.
- `todo/pilot-plaque-form.md` — пилот 2: форма 69 через тестовую копию, затем боевая. Нужны рецепты из первой задачи и эталон `price` ≈ 6205.71 на боевом API.

## Порядок

1. `todo/skills-recipes.md`
2. `todo/pilot-plaque-form.md` — после merge рецептов в `main`. Если боевой API ещё не отдаёт эталон плакеток — стоп, форму не переключать.

Модель чата — поле `Implementer` в шапке задачи. Человек открывает новый чат с этой моделью, не с той, что уже открыта «под рукой».
