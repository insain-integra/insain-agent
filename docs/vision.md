Утверждено владельцем 07.11.2026. Меняет только владелец; эпики в `todo/` ссылаются на цели G1–G6.

## Миссия

Один человек ведёт сайт, расчёт цен и контент Инсайна через ИИ-агентов. Клиент сам считает
цену на сайте и оставляет заявку, менеджер считает быстро и без ошибок, цены одни везде.

### G6 — критерии

Из «Критериев успеха» `docs/refactoring-plan.md`:

1. Любое изменение в любом контуре проходит один цикл, и агент по `AGENTS.md` выполняет его без устных пояснений.
2. Цены на сайте и в API совпадают и меняются в одном месте; расхождение невозможно по процессу, а не по дисциплине.
3. Состояние прода (сайт, формы, API, версии) описано в репозитории, совпадает с реальностью и проверяется командой.
4. Новая форма, калькулятор, правка страницы или товара делаются по рецепту (skill) с проверкой результата на сайте.
5. Бот не деградирует: его тесты входят в `make check`.

## Как идём к G1

Формы переключаются пачками по 5–10, копии принимаются выборочно. Формы без калькулятора
в API (медали, брелоки, брошюры и другие из `BACKLOG.md`) сначала получают калькулятор.

## Ограничения

- Время владельца — больше 20 ч в неделю.
- Цены — только в git. Прод меняется по циклу задача → агент → проверка → ревью → деплой.
- Доступы к Метрике и amoCRM — вне git, как ключи на проде.
