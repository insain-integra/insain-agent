## Исходное состояние на 19.02.2026

- Сайт insain.ru на WordPress. Расчёт цен — 39 калькуляторов на JS (`js_legacy/`), подключены
  в формы ez Form Calculator через лоадер `/icalc/`.
- Цены, наценки и сроки — в JS и JSON старого калькулятора на сервере сайта, без истории изменений.
- Нет API расчёта, нет тестов, нет репозитория с историей изменений.
- Нет ИИ-консультанта для менеджеров.
