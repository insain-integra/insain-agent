# Расход ИИ-агентов

Доля моделей в токенах и стоимости по выгрузке Usage из кабинета Cursor. Цель — Opus только на
сложных шагах (правило выбора модели — `docs/agents/roles/analyst.md`), основная работа — Grok и Auto.

Как снять: кабинет Cursor → Usage → выгрузка CSV за период, затем
`python scripts/dev.py usage <файл.csv>`. Раз в неделю; строка за тот же период заменяется.
«Стоимость, $» — колонка стоимости из CSV: запросы, вошедшие в тариф, там могут быть нулём.
«Кэш, % входа» — доля входных токенов, прочитанных из кэша: чем выше, тем дешевле длинные сессии.
