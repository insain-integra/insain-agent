# История проекта

Фактическая история работ: что было, что сделано, за какой срок и с какими затратами. Источник
для отчётов и кейсов. Рекламный текст здесь не пишется: кейс собирается из этих файлов отдельно.

| Файл | Что | Когда пополняется |
| --- | --- | --- |
| [passport.md](passport.md) | Дата старта, цель, исходное состояние | один раз; правка — только уточнение фактов |
| [log.md](log.md) | Журнал крупных задач и этапов | команда `python scripts/dev.py close <имя>` |
| [snapshots.md](snapshots.md) | Срезы состояния с одинаковым набором метрик | та же команда, если в месяце ещё нет среза |

## Правила

- Только факты с источником: коммит, команда, документ. Оценка помечается словом «оценка».
- В журнал — задачи обычного и прод режима и эпики. Быстрые правки не записываются.
- Запись собирает `scripts/dev.py close` из «Результата», «Журнала передач» и чатов Cursor. Вручную журнал не заполнять.
- Новая запись — сверху. Прошлые записи не переписываются, ошибка исправляется припиской.
- Нельзя: секреты, адреса и порты сервера, внутренние `code` материалов, закупочные цены и наценки,
  персональные данные клиентов.

## Три вида времени

- **Срок** — от первого до последнего сообщения в чатах задачи; без чатов — по `git log` файла задачи
  (он включает время, пока задача лежала черновиком).
- **Часы человека** — сумма интервалов между сообщениями владельца в чатах задачи; интервал длиннее
  30 мин — перерыв, не считается. Чат задачи — тот, где `todo/<имя>` есть в первом сообщении.
  Нет локальных чатов — строка «чаты Cursor не найдены». Старые записи до 07.11.2026: оценка 1 ч на коммит.
- **Работа агентов** — число чатов задачи, сообщений человека и активных часов, модели из шапки.

## Формат записи в `log.md`

```markdown
## ГГГГ-ММ-ДД — <название>

- Период: ГГГГ-ММ-ДД — ГГГГ-ММ-ДД (N дн.)
- Часы человека: оценка N ч (1 ч на коммит) | N ч (факт)
- Работа агентов: N сессий; Implementer — <модель>, Reviewer — <модель>
- Было: <одна-две строки>
- Стало: <одна-две строки, с числами>
- Эффект: <что стало быстрее, дешевле, надёжнее>
- Источник: <коммиты, задача, документ>
```
